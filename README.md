# Finanças — Downloads

Aqui ficam as versões do **Finanças para computador**, o app que organiza o seu dinheiro de um jeito simples, claro e seguro.

## Sobre o Finanças

- **Lance em poucos toques** ou só conte para a **Fin**, a assistente do app, o que você gastou.
- **Veja o mês de relance:** saldo, receitas, despesas e relatórios, sem planilha.
- **Suas finanças são só suas:** sem senha para decorar e com os dados protegidos.
- **Em todos os lugares:** a mesma conta no celular, no computador e no site.

## Baixar

1. Abra a aba [**Releases**](../../releases) deste repositório.
2. Escolha a versão mais recente e baixe o instalador para Windows.
3. Abra o arquivo e siga os passos na tela.

Depois de instalado, o app avisa quando houver uma versão nova.
